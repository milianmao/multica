## 最常被问到的三个「为什么」

- **为什么不能加数据库外键？** → [D3](关键设计决策.md#d3--无外键无级联关系与清理写在应用层)
- **为什么 Query `staleTime` 是 Infinity？** → [D10](关键设计决策.md#d10--客户端新鲜度押在-websocket-上)
- **为什么 agent 没跑起来却没有报错？** → 不该发生；[统一准入契约](设计模式与策略.md#1-统一准入契约admission) 规定必须返回 `blocked + reason_code`
