## 阅读顺序建议

1. 先读 [系统分层架构](系统分层架构.md) 的「五层结构」与「共享包边界」两节。
2. 需要动环境就读 [部署与运行架构](部署与运行架构.md) 的「本地环境管理」。
3. 需要改依赖或加中间件再读 [技术栈与中间件](技术栈与中间件.md)。

## 三句话概括

- 后端是**单进程单体**（`cmd/server`），靠 `internal/` 包边界划分，不靠独立服务拆分。
- 计算不在服务器上跑——服务器只排队与记录，**agent 进程在用户机器的 daemon 里**。
- 前端三端共享 `core`（无头）+ `views`（页面），平台差异收敛到 app 层的 `platform/` 目录。
