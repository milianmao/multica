## 提交前的硬门禁（会被 CI 拦）

- [ ] `pnpm typecheck` 通过
- [ ] 改了 SQL → `make sqlc`，生成物已提交
- [ ] 改了保留 slug → `pnpm generate:reserved-slugs`
- [ ] 新增索引 → `CONCURRENTLY` + 单语句文件 + 登记 `cmd/migrate/main.go`
- [ ] UI/交互改动 → PR 附截图或录屏
- [ ] 没有中文注释、没有 TODO/占位实现
