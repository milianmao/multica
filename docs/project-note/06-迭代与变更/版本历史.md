## 发布流程要点

1. 从 `main` 上已评审的提交打 tag：`vX.Y.Z`。
2. `verify` 任务先跑 Go 测试 + `govulncheck`（fail-closed），任一失败则不发布。
3. 发布产物：CLI 二进制（Homebrew tap）、后端与 web 多架构镜像（GHCR）、Helm chart、桌面安装包。
4. 默认补丁版本递增，除非明确指定。
