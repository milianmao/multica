## 何时需要更新知识库

| 触发 | 范围 |
|---|---|
| 新增/变更核心业务流 | 追加 `03-核心数据业务流/[流程].md` |
| 架构分层或包边界变化 | 增量更新 `01`、`04` |
| 修完一个有价值的 bug | 视 `fix-bug-workflow` Step 9 的结论，定点追加到 [已知问题与陷阱](已知问题与陷阱.md) |
| 超过 14 天未更新但代码基线已前移 | 增量刷新（`--incremental`） |
