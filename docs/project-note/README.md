## 这是什么项目

Multica 是一个「人 + AI 编码智能体」共用的工作区：把 Issue 指派给 agent，agent 在你自己的机器上（daemon 拉起的 AI CLI）执行，过程与结果实时回流到 Web / Desktop / Mobile。服务器只做排队、编排与记录。

## 给 AI 的阅读指南

1. **先读本页**，用上面的表定位到 1–2 篇 L2 索引。
2. **再读 L2 索引**（各分类 `README.md`），按一句话摘要挑中 L3。
3. **只读命中的 L3**。每篇 L3 的 frontmatter 有 `source_files`，可用来判断是否过期（对比文件 git mtime）。
4. 需要跨文档细节时，走文档里的 `→ 详见` 链接，不要重新读一遍源码。

Token 成本参考：L1 ≈ 200 tokens，L2 ≈ 150/篇，L3 ≈ 1000–3000/篇。
