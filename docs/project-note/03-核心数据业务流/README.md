## covered 判据

每篇均含：① 触发点（方式 + 前置条件）② 数据流路径（含关键文件:行）③ 异常路径（降级/超时/冲突/不可用）。边界场景写在「异常路径」段内。

## 一条链路的全景（跨文档索引）

```
人点"指派给 agent"
  → Agent任务生命周期（入队/领取/执行/终态）
  → 实时事件广播链路（task:* 事件到达浏览器）
  → Chat会话与流式回复（若是 chat 任务，token 如何流式出现）
自动化产生 run → 自动化调度链路 → 汇入 Agent任务生命周期
外部渠道消息 → 外部渠道机器人接入 → 汇入 Chat会话与流式回复
所有请求先过 → 认证与工作区作用域
```
